## About the Organisation
Haniya Cafes is a small cafe where staff shifts are currently planned by hand. This system digitises staff records and shift scheduling.

## Requirements
- Staff: add, view, search, filter, sort, edit, mark inactive, delete (only if the person has no shifts)
- Shifts: schedule, view, filter by date, sort, edit, delete
- Rules: inactive staff cannot be given shifts, end time must be after start time, a person cannot have overlapping shifts
- Users: the cafe manager
- Proof of concept: CRUD for staff and shifts. A full system could also include attendance and payroll.
